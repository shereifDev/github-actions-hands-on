**Exercise 1: The "Hello Actions" Initialization**
* **Objective:** Create a foundational workflow that executes automatically when pushing code to the main branch, printing a welcome message to the console.
* **Concepts Used:** `on: push`, `runs-on`, `steps`, `run`.
* **Expected Result:** A successful workflow run in the Actions tab displaying "Hello, DevOps!" in the step logs.
* **Note:** Every pipeline starts with understanding how to trigger a runner and execute basic shell commands.
