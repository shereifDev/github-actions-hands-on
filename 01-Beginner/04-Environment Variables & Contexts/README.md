**Exercise 4: Environment Variables & Contexts**
* **Objective:** Define a custom environment variable globally (workflow level) and print it using a shell command.
* **Concepts Used:** `env`, `run: echo $VAR_NAME`.
* **Expected Result:** The workflow prints the value of the custom variable (e.g., AUTHOR: Sherif).
* **Note:** Environment variables can be scoped to the entire workflow, a specific job, or a single step.
