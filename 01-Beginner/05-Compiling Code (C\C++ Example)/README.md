**Exercise 5: Compiling Code (C/C++ Example)**
* **Objective:** Create a step that compiles a simple `main.c` file using the GNU Compiler Collection (GCC).
* **Concepts Used:** `runs-on: ubuntu-latest`, `run: gcc main.c -o app`.
* **Expected Result:** The C file compiles without errors, generating an executable named `app`.
* **Note:** `ubuntu-latest` runners come pre-installed with many development tools, including GCC and Python.
